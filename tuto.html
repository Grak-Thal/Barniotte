Créer un groupe

Ton groupe a son propre Google Sheet. L’appli est la même pour tous, mais personne d’autre ne voit tes données.

Avant de commencer

  • Une personne organise : elle crée le Sheet avec son compte Google (gratuit). Les autres n’ont rien à créer, juste à ouvrir un lien.
  • Un ordinateur pour cette installation (15 minutes, une seule fois). Ensuite, tout se fait sur téléphone.
  • Qui voit quoi ? Les matchs sont enregistrés dans ton Sheet, sur ton Google Drive. L’auteur de cette appli n’y a aucun accès et ne reçoit aucune donnée de ton groupe.
1

Crée le Sheet

  1. Connecte-toi à ton compte Google, puis ouvre sheets.new : un tableur vide s’ouvre.
  2. Donne-lui un nom, par exemple « Barniotte de l’équipe ».

Garde ce Sheet privé. Ne le partage pas par lien et ne l’ouvre pas à d’autres personnes : l’appli passe par un script, pas par un accès direct au Sheet.

2

Génère le code d’accès

Ce code protège les données de ton groupe : sans lui, ni l’appli ni personne ne peut lire ou écrire dans ton Sheet. Il est créé ici, dans ton navigateur, et n’est envoyé nulle part.

J’ai déjà un code (mise à jour du script)

Pour mettre à jour le script d’un groupe existant sans changer de code : saisis ton code actuel (16 caractères minimum, lettres, chiffres et tirets).

Garde ce code dans un endroit sûr (gestionnaire de mots de passe, par exemple). Tu en auras besoin à l’étape 3, à l’étape 6 et pour changer ou mettre à jour le script plus tard. Si tu rouvres cette page, il faudra en générer un autre : n’utilise que celui que tu as collé dans le script.

3

Colle le script dans le Sheet

  1. Dans le Sheet, clique sur Extensions, puis Apps Script. Un nouvel onglet s’ouvre.
  2. Dans l’éditeur, sélectionne tout le code qui s’y trouve (Ctrl+A) et supprime-le.
  3. Reviens ici, clique sur le bouton ci-dessous, puis colle dans l’éditeur (Ctrl+V).
  4. Clique sur l’icône disquette Enregistrer.

Si tu coches, chaque joueur crée un code à 6 chiffres la première fois qu’il choisit son nom dans l’appli, et le redonne en changeant de téléphone. Cinq essais ratés bloquent le nom 15 minutes. C’est utile si tout le monde ne se connaît pas bien. Tu peux le changer plus tard.


Avec les codes PIN, seuls les administrateurs peuvent ouvrir ou clôturer une saison, ajouter ou retirer des joueurs, corriger un match terminé et changer le code d’accès. Tu pourras nommer d’autres administrateurs depuis l’appli. Écris-le exactement comme tu le choisiras dans l’appli (les majuscules et accents sont tolérés).

Le bouton se débloque dès que ton code est généré (étape 2). Le script contient déjà ton code.

Voir le script (version 5)

Rien de caché : tu peux le relire. Il lit et écrit uniquement dans ce Sheet (4 onglets : Joueurs, Saisons, Matchs, Journal) et ne contacte aucun autre service. Les codes PIN ne sont jamais enregistrés : seule une empreinte l’est, dans les propriétés du script.

4

Installe les onglets

  1. En haut de l’éditeur Apps Script, dans la liste à côté de Exécuter, choisis installer.
  2. Clique sur Exécuter.
  3. Google demande une autorisation : Examiner les autorisations, choisis ton compte, puis Paramètres avancés, Accéder à … (non sécurisé) et Autoriser.
  4. Reviens dans le Sheet : il contient maintenant 4 onglets (Joueurs, Saisons, Matchs, Journal).

L’avertissement « Google n’a pas validé cette application » est normal : c’est ton propre script, que Google n’a pas examiné. Le script ne demande que l’accès à ce Sheet.

5

Publie le script

  1. Dans l’éditeur Apps Script, clique sur Déployer (en haut à droite), puis Nouveau déploiement.
  2. Clique sur la roue dentée à côté de « Sélectionner le type », puis choisis Application Web.
  3. Exécuter en tant que : Moi.
  4. Qui a accès : Tout le monde.
  5. Clique sur Déployer, autorise si Google le redemande, puis copie l’URL de l’application Web (elle finit par /exec).

« Tout le monde », pas « Tout le monde avec un compte Google ». Avec le second choix, l’appli affiche « Impossible de joindre le serveur » sur les téléphones. « Tout le monde » ne veut pas dire que tout le monde peut lire tes données : sans le code d’accès, le script ne répond rien.

6

Crée le lien d’invitation

Colle ici l’URL copiée à l’étape 5. Le lien d’invitation contient l’adresse de ton script et ton code : c’est ce qui permet aux joueurs de rejoindre ton groupe en un clic.

Tester le lien

Ce lien est la clé de ton groupe. Envoie-le seulement aux joueurs, par message privé. Ne le publie pas. Si quelqu’un d’extérieur l’obtient, change le code (voir « Entretien » plus bas).

7

Lance ta première saison

  1. Ouvre le lien d’invitation sur ton téléphone ou ton ordinateur, puis confirme Rejoindre.
  2. Va dans l’onglet Gestion : ajoute les joueurs un par un.
  3. Toujours dans cet onglet, choisis les joueurs classés, le nombre de matchs par duo, puis clique sur Ouvrir la saison.
  4. Choisis ton nom quand l’appli demande « Qui es-tu ? ». C’est le bouton + qui lance un match.
  5. Envoie le lien d’invitation aux autres joueurs. Pour que l’appli reste sur l’écran d’accueil : sur iPhone, bouton Partager de Safari puis « Sur l’écran d’accueil » ; sur Android, menu ⋮ de Chrome puis « Ajouter à l’écran d’accueil ».

Les règles de l’appli sont celles de la Barniote : le premier à 7 points gagne, il n’y a pas de match nul. Le bouton Règles de l’onglet Gestion ouvre le texte complet.

Sauvegarde automatique (facultatif)

Ton Sheet garde déjà l’historique des versions de Google. Pour une copie de plus, ce petit script ajoute une copie du Sheet chaque semaine dans ton Drive et ne garde que les 4 dernières.

Il demande une autorisation de plus : l’accès à ton Google Drive. Le script ne touche qu’à son propre dossier « Barniotte - Sauvegardes », mais comme Google ne propose pas d’autorisation plus étroite, la fenêtre parle de « supprimer des fichiers ». Si cela ne te convient pas, saute cette étape.
  1. Dans l’éditeur Apps Script, clique sur + à côté de « Fichiers », puis Script, et nomme-le « Sauvegarde ».
  2. Supprime son contenu, puis colle le script ci-dessous et enregistre.
  3. Choisis activerSauvegardeHebdo dans la liste, puis Exécuter, et autorise.

Entretien

Mettre à jour le scriptQuand l’appli indique dans l’onglet Gestion que le script du groupe n’est pas à jour, reviens sur cette page. À l’étape 2, ouvre « J’ai déjà un code » et saisis ton code actuel, puis fais l’étape 3. Ensuite, la Nouvelle version du déploiement (comme ci-dessus). L’adresse du script ne change pas : les liens déjà envoyés fonctionnent toujours.
Activer ou arrêter les codes PINDans le script, ligne const PIN_ACTIF = …; : true pour activer, false pour arrêter. Enregistre, puis Déployer → Gérer les déploiements → crayon → Version : Nouvelle version → Déployer. Les codes déjà créés sont conservés.
Changer le code d’accès du groupe, nommer un administrateurDans l’appli, onglet Gestion, carte Administration (réservée aux administrateurs). Le nouveau lien d’invitation s’affiche : envoie-le aux joueurs de confiance. Une fois le code changé dans l’appli, la ligne const CODE du script est ignorée ; pour revenir à elle, lance la fonction oublierCodeAppli dans l’éditeur.
Un joueur a oublié son code PINDans le script, écris son nom entre les guillemets de const JOUEUR_PIN_A_REINITIALISER = '';, enregistre, choisis la fonction reinitialiserPin dans la liste et clique sur Exécuter. Il crée un nouveau code en choisissant son nom dans l’appli.
Ajouter ou retirer un joueurDans l’appli, onglet Gestion, section Joueurs. Un joueur ajouté joue à partir de la saison suivante.
Corriger un matchDans l’appli : onglet Matchs, ouvre le match. Les corrections sont notées dans le journal.
Supprimer un match de testDans le Sheet, onglet Matchs, remplace termine par annule dans la colonne statut.
N’efface pas, ne renomme pas et ne déplace pas les colonnes ni les onglets du Sheet : l’appli ne s’y retrouverait plus. Tu peux le consulter ou ajouter des colonnes à droite.

Ça ne marche pas ?

MessageCause probable
« Impossible de joindre le serveur »Le déploiement n’est pas sur « Tout le monde » (étape 5), ou l’appareil n’a pas de réseau. Après correction, recharge l’appli (Ctrl+F5 sur ordinateur).
« Code refusé »Le code saisi n’est pas celui de la ligne const CODE du script. Vérifie qu’il n’y a pas d’espace avant ou après.
« Ce lien ne mène pas à un groupe Barniotte »L’URL du script est incomplète ou le script n’est pas publié. Ouvre l’URL dans un navigateur : tu dois voir {"ok":true,"service":"Barniotte"…}.
Rien ne s’enregistre dans le SheetL’étape 4 (installer) n’a pas été lancée, ou un onglet a été renommé.
Une ancienne version s’afficheFerme complètement l’appli et rouvre-la. Sur ordinateur, Ctrl+F5.
Une erreur d’exécution dans Apps ScriptLe texte du code a pu être mal collé. Recommence l’étape 3 en supprimant bien tout l’ancien contenu.
